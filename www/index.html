Guia de Integração para Desenvolvedores

Como conectar seu computador de desenvolvimento à rede mesh em segundos.

01

Instalar e Autenticar no Tailscale

Execute no terminal da sua máquina de desenvolvimento com a Auth Key fornecida pelo projeto:

tailscale up --authkey=tskey-auth-xxxxx --accept-routes
02

Subir o Container de Desenvolvimento

Inicie seu serviço docker escutando na porta configurada no Nginx:

docker run -d --name meu-backend -p 8000:8000 minha-api:dev
03

Acessar Imediatamente via Edge Cloudflare

O Cloudflare Worker e o Nginx identificam o host MagicDNS e encaminham o tráfego com SSL automático.

curl -I https://seu-dominio.workers.dev/api/v1/health
